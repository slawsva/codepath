# CodePath

Учебный каталог курсов по программированию, анализу данных и машинному обучению. Автор — Святослав Сакулин, группа 12-40.

Откройте `index.html` в браузере. Для запуска через локальный сервер выполните `python3 -m http.server 8000` в папке проекта и перейдите на http://localhost:8000. Bootstrap CSS и JS лежат в `vendor/`, иллюстрации — в `images/`, поэтому интернет для просмотра не нужен.

| Страница | Содержание |
| --- | --- |
| `index.html` | Введение, подборка курсов и вопросы и ответы |
| `catalog.html` | Каталог с поиском, фильтрами, сортировкой и избранным |
| `learning.html` | Формат занятий на примере модуля по Python |
| `projects.html` | Примеры итоговых работ с переходами к программам |
| `product.html?course=python` | Карточка курса: программа, требования, длительность и цена |
| `order.html` | Форма записи, в том числе с предварительным выбором курса |

Форма демонстрационная: данные не отправляются и не сохраняются. Курсы, цены и примеры работ предназначены для учебного проекта.

В проекте используются сетка Bootstrap, Navbar, Card, Badge, Modal, Accordion, Alert, Input Group и Form Check. Общие стили находятся в `css/custom.css`, данные курсов и логика фильтрации и записи — в `js/app.js`.

## Практики 9–11

- №9: локальный Bootstrap Bundle, сетка `container` / `row` / `col-*`, адаптивные колонки и отступы.
- №10: компоненты Bootstrap на главной, в каталоге, в карточке курса и в форме.
- №11: медиазапросы, адаптивная графика, прокручиваемая при необходимости таблица, подписи полей, видимый фокус и ссылка перехода к основному содержимому.
