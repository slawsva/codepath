Как выбрать программу

Начните с уровня

Python, Frontend и SQL подходят для знакомства с направлением. Для анализа данных и машинного обучения сначала проверьте требования на странице курса.

Сравните результат

В каждой программе есть итоговая работа. Выберите задачу, которую хочется решить, и посмотрите, какие темы понадобятся для её выполнения.
